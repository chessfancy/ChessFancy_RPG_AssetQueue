# Global Art Style Bible

This directory stores durable visual laws shared across ChessFancy RPG asset workers.

## Exploration maps

- polished hand-painted 2D JRPG environment art
- top-down / high-oblique exploration perspective
- clear traversable paths and readable cliff/edge safety
- consistent terrain scale between connected scenes
- environment continuity matters more than isolated spectacle

## Character / canonical references

- child-friendly Vietnamese fantasy JRPG language
- strong readable silhouettes at gameplay scale
- preserve defining face, hair/fur, costume, armor, weapon, accessories and proportions once canonical identity is locked
- no silent redesign drift across later generations

## Battle sprites

- side-view readability first
- full body and important weapons/parts remain visible
- high-resolution creative/master source; runtime cell size is a later delivery constraint
- stable apparent scale and baseline after post-processing
- action must read at gameplay size

## Connected-scene laws

When a region contains multiple maps, preserve across the batch:

- geology / terrain material
- vegetation family
- lighting/time of day unless story requires a transition
- path width and traversal logic
- architecture/prop language
- edge-to-edge route continuity

## Prop laws

- props inherit the chapter biome/material language
- gameplay readability beats ornamental clutter
- props intended for extraction should have clean separation and generous padding
- remove temporary planning/construction clutter from clean basemaps unless the story specifically requires it

## QC priorities

1. identity/style continuity
2. route/action readability
3. no true crop/bleed
4. correct technical format
5. fine pixel polish
